## 简介

### Stack 

栈。

Java 的 `Stack` 是基于 `Vector` 的线程安全栈（LIFO），但由于继承结构不合理、同步方式老旧，被官方标为过时设计， 已经不推荐使用了。

### Queue 

队列。

`Queue` 是 Java 中表示 **FIFO 队列** 的接口， 常见实现有 `ArrayDeque`、`LinkedList`、`PriorityQueue` 等。
实际开发中推荐 `ArrayDeque` 实现普通队列。
而 `PriorityQueue` 实现按优先级出队的队列，不是 FIFO。详情见另一篇：

### Deque

双端队列。

`Double Ended Queue`

Deque 是双端队列接口，支持在队头和队尾插入和删除元素。它既可以作为队列（FIFO），也可以作为栈（LIFO）。典型实现是 `ArrayDeque` 和 `LinkedList`。

```text
Collection
   ↑
  Queue
   ↑
  Deque
```
