## Mybatis 
<details class="lake-collapse"><summary id="uf9741537"><strong><span class="ne-text">Mybatis 是什么</span></strong></summary><p id="u458f5859" class="ne-p"><span class="ne-text" style="color: rgb(51, 51, 51)">MyBatis 是一款</span><strong><span class="ne-text" style="color: rgb(51, 51, 51)">优秀的持久层框架</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">，它本质上是一个 </span><strong><span class="ne-text" style="color: rgb(51, 51, 51)">ORM（对象关系映射）框架</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">，用于帮助我们将 </span><strong><span class="ne-text" style="color: rgb(51, 51, 51)">Java 对象与数据库中的 SQL 操作绑定起来</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">。</span></p><p id="ufafc6be6" class="ne-p"><span class="ne-text" style="color: rgb(51, 51, 51)">它的核心思想是：</span><strong><span class="ne-text" style="color: rgb(51, 51, 51)">通过 XML 或注解方式将 SQL 与 Java 方法进行映射</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">，程序员自己编写 SQL，而 MyBatis 负责将结果映射成对象并执行。</span></p></details>
<details class="lake-collapse"><summary id="u1a953d4a"><strong><span class="ne-text">有什么特点，和传统 JDBC 相比有什么优点</span></strong></summary><h3 id="aOXIe"><span class="ne-text" style="color: rgb(51, 51, 51)">特点</span></h3><ol class="ne-ol"><li id="u3572da9f" data-lake-index-type="0"><strong><span class="ne-text" style="color: rgb(51, 51, 51)">半自动化 ORM 框架</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">：不像 Hibernate 那样全自动，SQL 需要开发者自己写，更加灵活、可控。</span></li><li id="u2e6cae97" data-lake-index-type="0"><strong><span class="ne-text" style="color: rgb(51, 51, 51)">支持自定义 SQL</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">：适合对 SQL 性能 要求高、业务复杂的场景。</span></li><li id="u5ab2f7af" data-lake-index-type="0"><strong><span class="ne-text" style="color: rgb(51, 51, 51)">支持动态 SQL</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">：通过 XML 标签动态生成 SQL（如 if、where、foreach）。</span></li><li id="uebf84ca0" data-lake-index-type="0"><strong><span class="ne-text" style="color: rgb(51, 51, 51)">提供映射机制</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">：支持将数据库结果映射为 Java 对象，支持一对一、一对多等关系映射。</span></li><li id="u71956a0a" data-lake-index-type="0"><strong><span class="ne-text" style="color: rgb(51, 51, 51)">集成简单</span></strong><span class="ne-text" style="color: rgb(51, 51, 51)">：可以轻松与 Spring/Spring Boot 集成。</span></li></ol><hr id="lnIds" class="ne-hr"><h3 id="62d236a4"><span class="ne-text" style="color: rgb(51, 51, 51)">与传统的JDBC相比，MyBatis的优点？</span></h3><ul class="ne-ul"><li id="u4a63b8a9" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">基于 SQL 语句编程，相当灵活，不会对应用程序或者数据库的现有设计造成任 何影响，SQL 写在 XML 里，解除 sql 与程序代码的耦合，便于统一管理；提供 XML 标签，支持编写动态 SQL 语句，并可重用。</span></li><li id="u1fe2e55d" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">与 JDBC 相比，减少了 50%以上的代码量，消除了 JDBC 大量冗余的代码，不 需要手动开关连接；</span></li><li id="u2c9257e1" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">很好的与各种数据库兼容，因为 MyBatis 使用 JDBC 来连接数据库，所以只要 JDBC 支持的数据库 MyBatis 都支持。</span></li><li id="u29012ee1" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">能够与 Spring 很好的集成，开发效率高。</span></li><li id="u93229254" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">提供映射标签，支持对象与数据库的 ORM 字段关系映射；提供对象关系映射 标签，支持对象关系组件维护。</span></li></ul><hr id="Gpw7y" class="ne-hr"><h3 id="p9siw"><span class="ne-text">与全自动化 ORM（如 Hibernate）的区别</span></h3><h4 id="L64CG"><span class="ne-text">全自动 ORM</span></h4><ul class="ne-ul"><li id="u78c7d537" data-lake-index-type="0"><span class="ne-text">自动生成 SQL</span></li><li id="u2613cecc" data-lake-index-type="0"><span class="ne-text">自动管理实体状态（增删改查）</span></li><li id="u905bc5ae" data-lake-index-type="0"><span class="ne-text">自动处理关联映射（1-1 / 1-N / N-N）</span></li><li id="uee7cb2aa" data-lake-index-type="0"><span class="ne-text">有完整的缓存、事务、脏检查等机制</span></li></ul><p id="ua1273cfc" class="ne-p"><span class="ne-text">开发者</span><strong><span class="ne-text">不用写 SQL，操作对象就行</span></strong><span class="ne-text">。</span></p><h4 id="S1eCO"><span class="ne-text">MyBatis</span></h4><ul class="ne-ul"><li id="u259c95cd" data-lake-index-type="0"><span class="ne-text">SQL 手写 → 灵活</span></li><li id="u1d89f3a8" data-lake-index-type="0"><span class="ne-text">映射自动 → 简化 JDBC</span></li><li id="u3bbf7272" data-lake-index-type="0"><span class="ne-text">不管理实体状态、不生成 SQL、不做关联推断</span></li></ul></details>
<details class="lake-collapse"><summary id="u07e815dc"><span class="ne-text">有什么缺点</span></summary><ul class="ne-ul"><li id="u5d64ef6c" data-lake-index-type="0"><span class="ne-text">SQL 语句的编写工作量较大，尤其当字段多、关联表多时，对开发人员编写 SQL 语句的功底有一定要求</span></li><li id="u0d00714f" data-lake-index-type="0"><span class="ne-text">SQL 语句依赖于数据库，导致数据库移植性差，不能随意更换数据库</span></li></ul></details>
<details class="lake-collapse"><summary id="udbd2ff53"><span class="ne-text" style="color: rgb(51, 51, 51)">Mybatis里的 # 和 $ 的区别？</span></summary><ul class="ne-ul"><li id="ub5db9eb8" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">Mybatis 在处理 #{} 时，会创建预编译的 SQL 语句，将 SQL 中的 #{} 替换为 ? 号，在执行 SQL 时会为预编译 SQL 中的占位符（?）赋值，调用 PreparedStatement 的 set 方法来赋值，预编译的 SQL 语句执行效率高，并且可以防止SQL 注入，提供更高的安全性，适合传递参数值。</span></li><li id="u7c9a7d8e" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">Mybatis 在处理 ${} 时，只是创建普通的 SQL 语句，然后在执行 SQL 语句时 MyBatis 将参数直接拼入到 SQL 里，不能防止 SQL 注入，因为参数直接拼接到 SQL 语句中，如果参数未经过验证、过滤，可能会导致安全问题。</span></li></ul></details>
## 原理
<details class="lake-collapse"><summary id="u25f89de8"><span class="ne-text">流程/原理</span></summary><ul class="ne-ul"><li id="u96588623" data-lake-index-type="0"><strong><span class="ne-text">读取配置</span></strong><span class="ne-text"><br /></span><span class="ne-text">加载 </span><code class="ne-code"><span class="ne-text">mybatis-config.xml</span></code><span class="ne-text">、映射文件、数据源等信息，创建 </span><code class="ne-code"><span class="ne-text">SqlSessionFactory</span></code><span class="ne-text">。</span></li><li id="u627bfcbb" data-lake-index-type="0"><strong><span class="ne-text">创建 SqlSession</span></strong><span class="ne-text"><br /></span><span class="ne-text">从 </span><code class="ne-code"><span class="ne-text">SqlSessionFactory</span></code><span class="ne-text"> 打开一个 </span><code class="ne-code"><span class="ne-text">SqlSession</span></code><span class="ne-text">，本质上是获取数据库连接并准备执行环境。</span></li><li id="u1fb093d4" data-lake-index-type="0"><strong><span class="ne-text">找到对应的 MappedStatement</span></strong><span class="ne-text"><br /></span><span class="ne-text">根据调用的 Mapper 方法（例如 </span><code class="ne-code"><span class="ne-text">UserMapper.selectById</span></code><span class="ne-text">）找到对应的 SQL 配置。</span></li><li id="ufdfa6ef5" data-lake-index-type="0"><strong><span class="ne-text">参数处理</span></strong><span class="ne-text"><br /></span><span class="ne-text">MyBatis 把方法参数绑定到 SQL 中（预编译的 </span><code class="ne-code"><span class="ne-text">?</span></code><span class="ne-text"> 占位符）。</span></li><li id="u1ce45ecb" data-lake-index-type="0"><strong><span class="ne-text">执行 SQL</span></strong><span class="ne-text"><br /></span><span class="ne-text">调用 JDBC 执行：</span><code class="ne-code"><span class="ne-text">PreparedStatement</span></code><span class="ne-text"> → 发给数据库 → 得到结果集。</span></li><li id="ub4d6fa38" data-lake-index-type="0"><strong><span class="ne-text">结果映射</span></strong><span class="ne-text"><br /></span><span class="ne-text">将结果集映射成 Java 对象（自动根据 </span><code class="ne-code"><span class="ne-text">&lt;resultMap&gt;</span></code><span class="ne-text"> 或字段名映射）。</span></li><li id="u844bcfcb" data-lake-index-type="0"><strong><span class="ne-text">返回对象</span></strong><span class="ne-text"><br /></span><span class="ne-text">把映射后的对象返回给调用者，</span><code class="ne-code"><span class="ne-text">SqlSession</span></code><span class="ne-text"> 关闭或进入事务管理流程。</span></li></ul></details>
<details class="lake-collapse"><summary id="u78a14735"><span class="ne-text"> 在Mapper中如何传递多个参数？  </span></summary><p id="u8d560940" class="ne-p"><span class="ne-text" style="color: rgb(25, 27, 31)">1、若Dao层函数有多个参数，那么其对应的xml中，#{0}代表接收的是Dao层中的第一个参数，#{1}代表Dao中的第二个参数，以此类推。</span></p><p id="u7f90a579" class="ne-p"><span class="ne-text" style="color: rgb(25, 27, 31)">2、使用@Param注解：在Dao层的参数中前加@Param注解,注解内的参数名为传递到Mapper中的参数名。</span></p><p id="ua6d12c10" class="ne-p"><span class="ne-text" style="color: rgb(25, 27, 31)">3、多个参数封装成Map，以HashMap的形式传递到Mapper中。</span></p></details>
<details class="lake-collapse"><summary id="uaa723f02"><span class="ne-text">动态sql有什么用？有哪些动态sql？</span></summary><p id="udb16d420" class="ne-p"><span class="ne-text"> 动态 SQL 用来 根据条件拼接 SQL，让查询逻辑更灵活  </span></p><h3 id="Co1sx"><span class="ne-text">常见动态 SQL 标签有哪些？</span></h3><p id="ubeb5badd" class="ne-p"><span class="ne-text">MyBatis 内置的动态 SQL 标签包括：</span></p><ol class="ne-ol"><li id="ucb580f47" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;if&gt;</span></strong></code><span class="ne-text"> —— 条件判断</span></li><li id="u0499dae3" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;choose&gt; &lt;when&gt; &lt;otherwise&gt;</span></strong></code><span class="ne-text"> —— 类似 switch-case</span></li><li id="ud81bb274" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;where&gt;</span></strong></code><span class="ne-text"> —— 自动加 WHERE，并去除多余 AND、OR</span></li><li id="u6ab37710" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;set&gt;</span></strong></code><span class="ne-text"> —— 自动处理 SET 子句的逗号</span></li><li id="ubb3df3e8" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;foreach&gt;</span></strong></code><span class="ne-text"> —— 遍历集合（常用于 IN、批量插入）</span></li><li id="ua7b8a140" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;trim&gt;</span></strong></code><span class="ne-text"> —— 自定义前后缀、去除多余字符</span></li><li id="uca805193" data-lake-index-type="0"><code class="ne-code"><strong><span class="ne-text">&lt;bind&gt;</span></strong></code><span class="ne-text"> —— 创建新的 SQL 变量</span></li></ol></details>
<details class="lake-collapse"><summary id="ue5ecb8ae"><span class="ne-text">一级、二级缓存</span></summary><p id="u66541ad7" class="ne-p"><span class="ne-text" style="color: rgb(25, 27, 31)">1、 一级缓存：基于PerpetualCache的HashMap本地缓存，其存储作用域为Session，当Session flush或close之后，该Session中的所有Cache就将清空，默认打开一级缓存。  </span></p><p id="u20a2e608" class="ne-p"><span class="ne-text" style="color: rgb(25, 27, 31)">2、 二级缓存与一级缓存机制相同，默认也是采用PerpetualCache，HashMap存储，不同在于其存储作用域为Mapper（namespace），并且可自定义存储源，如Ehcache。默认打不开二级缓存，要开启二级缓存，使用二级缓存属性类需要实现Serializable 序列化接口（可用来保存对象的状态），可在它的映射文件中配置。</span></p></details>
### 设计模式
<details class="lake-collapse"><summary id="ude7340eb"></summary><ul class="ne-ul"><li id="ue59b5a7e" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">建造者模式（Builder），如：SqlSessionFactoryBuilder、XMLConfigBuilder、XMLMapperBuilder、XMLStatementBuilder、CacheBuilder等；</span></li><li id="ud958e316" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">工厂模式，如：SqlSessionFactory、ObjectFactory、MapperProxyFactory；</span></li><li id="u2c89d3dc" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">单例模式，例如ErrorContext和LogFactory；</span></li><li id="u649e93ed" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">代理模式，Mybatis实现的核心，比如MapperProxy、ConnectionLogger，用的jdk的动态代理；还有executor.loader包使用了cglib或者javassist达到延迟加载的效果；</span></li><li id="uac479457" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">组合模式，例如SqlNode和各个子类ChooseSqlNode等；</span></li><li id="u37d045e8" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">模板方法模式，例如BaseExecutor和SimpleExecutor，还有BaseTypeHandler和所有的子类例如IntegerTypeHandler；</span></li><li id="uba0c042f" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">适配器模式，例如Log的Mybatis接口和它对jdbc、log4j等各种日志框架的适配实现；</span></li><li id="u1f9ce370" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">装饰者模式，例如Cache包中的cache.decorators子包中等各个装饰者的实现；</span></li><li id="u436c60aa" data-lake-index-type="0"><span class="ne-text" style="color: rgb(51, 51, 51)">迭代器模式，例如迭代器模式PropertyTokenizer；</span></li></ul></details>
